# 요구사항 정의서

## 프로젝트 개요

`옷장을 부탁해`는 사용자의 프로필, 보유 의상, 날씨 정보를 기반으로 개인화된 의상 조합을 추천하고, 이후 OOTD 피드와 소셜 기능으로 확장하는 백엔드 포트폴리오 프로젝트다.

## 단계 기준

| 단계 | 기준 |
| --- | --- |
| 초기 세팅 | 프로젝트 구현을 시작하기 위한 개발 환경, 문서, 공통 기반 구성 |
| MVP | 회원가입/로그인부터 프로필, 의상 등록, 날씨 조회, 의상 추천까지 핵심 흐름 완성 |
| v1 | MVP 이후의 소셜 기능, 관리자 기능, 알림, 검색, 배치, 분산 환경 등 확장 기능 |
